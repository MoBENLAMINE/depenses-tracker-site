# Dépenses Tracker — site

Site vitrine de l'application Android **Dépenses Tracker** (suivi des dépenses en dirhams, 100 % hors ligne).

- Site : https://mobenlamine.github.io/depenses-tracker-site/
- Politique de confidentialité : https://mobenlamine.github.io/depenses-tracker-site/confidentialite.html

Site statique (HTML/CSS/JS, sans build), publié avec GitHub Pages depuis la branche `main`.
La démo dans la page tourne entièrement dans le navigateur, avec des données d'exemple.
