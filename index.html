Questions fréquentes

Faut-il une connexion Internet ?

Non. Internet ne sert qu'à deux options facultatives : la sauvegarde Google Drive et le téléchargement du modèle IA.

Où sont stockées mes données ?

Dans une base de données locale, sur votre téléphone. La sauvegarde automatique d'Android est désactivée, et nous n'avons aucun serveur qui les reçoit.

Combien coûte l'application ?

Elle est gratuite. Premium est en option : 79,99 MAD, payés une seule fois sur Google Play. Ce n'est pas un abonnement, et les fonctions Premium à venir sont déjà comprises.

Que se passe-t-il si je change de téléphone ?

Avec Premium, faites une sauvegarde vers votre Google Drive ou exportez vos données, puis restaurez-les sur le nouvel appareil.

Et si je désinstalle l'application ?

Vos données sont supprimées avec elle. Si vous avez Premium, faites une sauvegarde ou un export avant.

L'IA envoie-t-elle mes dépenses quelque part ?

Non. Le modèle est téléchargé une seule fois, puis il tourne sur votre téléphone. Vos questions et vos chiffres ne quittent pas l'appareil.

Quelqu'un peut-il ouvrir l'app sur mon téléphone ?

Vous pouvez la verrouiller avec votre empreinte ou le code de l'appareil. Sans cela, elle reste fermée.

Est-ce disponible sur iPhone ?

Pas pour l'instant : l'application est disponible sur Android.

Dans quelle devise sont les montants ?

En dirhams marocains (MAD).
